**Chart 2 — BYDDY close, Aug–Oct 2026 (zoom on the significant-movement)**

**Chart 3 — Distribution of daily returns (boxplot)**
TSLA had the widest daily swings (std ≈ 3.03%) and BYDDY the smallest, so TSLA was the most volatile of the three.

**Chart 4 — BYDDY vs XPEV daily returns (scatter)**
The two stocks' daily returns are positively correlated (r ≈ 0.50), consistent with the two Chinese EV makers moving together.
